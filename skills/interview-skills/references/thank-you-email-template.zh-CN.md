# 感谢邮件模板

复盘用户自己的面试后，默认采用用户提供的模板结构生成邮件。英文参考文件完整保留原模板；本文件提供对应中文翻译与可复用草稿，实际使用时依据真实交流和已确认的候选人事实调整。

## 使用与调整规则

- 按顺序组织：主题与称呼 → 感谢 → 岗位／团队匹配 → 可选的问题补充 → 持续兴趣与补充信息 → 结尾。
- 将 `Dennis Gu`、`2024` 和 `IBD summer intern` 视为原例子的内容，不当作当前用户的姓名、年份或岗位。替换为已确认信息，或保留可见占位符。
- 只有确认了偏好称谓与姓氏时，才使用 `Mr.` 或 `Ms.`。否则使用不推断性别的 `Dear [面试官姓名]:`。
- 匹配段落以已确认的用户经历和真实岗位／团队讨论为依据。证据不足时，表达持续兴趣，不编造能力经历或团队需求。
- 只有该问题确实在面试中被问过，并且用户或代理已完成相关研究、得到已核实的发现时，才加入研究补充段落。研究来源另列在草稿之外。没有证据时，不得将 `After some research, I found...` 写成已经完成的行动。
- 尚未完成补充研究时，省略该段，或保留明确标注为可选的占位符。用户模板允许简洁且经过核实的答案补充，不代表允许编造研究、加入冗长改正答案或无关附件。
- 只有用户为该草稿提供手机号时，才加入号码。后续安排使用已知信息，或中性地提及下一步；不编造决定日期。将草稿视为可发送版本前，需要解决所有剩余占位符。
- 必要时，用户指定的模板优先于通常的 100–150 个英文词长度建议。用户要求双语时，提供含义一致的中文和英文草稿；只生成草稿。

## 原模板的中文对应翻译

```text
主题：[感谢] Dennis Gu 应聘 2024 年 IBD 暑期实习岗位

尊敬的 [姓氏] 先生／女士：

感谢您在百忙之中抽出时间，与我交流 [xxx] 公司 [xxx] 岗位的情况。

感谢您为此次面试付出的时间与考虑。在与您及团队交流后，我相信自己能够适合 [xxx 公司] 和 [xxx 团队]。

面试中，您向我提出了 [xxx 问题]。经过进一步研究，我了解到 [xxxxxx]。

我非常期待与您一起工作并向您学习，也期待在该岗位最终决定作出后收到您的消息。如需任何补充信息，请随时联系我。我的手机号码是 [xxx]。

再次感谢您的时间与考虑。

此致，

XXX
```

## 可复用草稿

```text
主题：[感谢] [你的姓名] 应聘 [年份，如适用] [岗位]

尊敬的 [面试官姓名，或已确认的称谓与姓氏]：

感谢您在百忙之中抽出时间，与我交流 [公司] 的 [岗位]。

感谢您的时间与考虑。我们关于 [真实讨论过的话题] 的交流，进一步增强了我加入 [公司] 和 [团队] 的兴趣。我在 [已确认的相关经历] 方面的经验，与交流中提到的 [有依据的岗位或团队需求] 相契合。

[可选——仅在核实后加入]
交流中，您问到了 [实际问题]。经过进一步研究，我发现 [已核实的发现及简要解释]。

我非常期待有机会与您和团队一起工作、向大家学习，并期待了解后续安排。如需任何补充信息，请随时联系我。[用户提供号码时可选：我的手机号码是 [号码]。]

再次感谢您的时间与考虑。

此致，
[你的姓名]
```
